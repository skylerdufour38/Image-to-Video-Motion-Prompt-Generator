# Image-to-Video Motion Prompt Generator

A browser-based AI video workflow prototype.

## Features

✅ Upload Image  
✅ Upload Audio  
✅ Optional Mask Upload  
✅ Motion Prompt Input  
✅ 1080p Resolution Selection  
✅ MP4 Preview  
✅ Download Video  

## Workflow

Image
↓
Audio
↓
Mask
↓
Motion Prompt
↓
Generate MP4
